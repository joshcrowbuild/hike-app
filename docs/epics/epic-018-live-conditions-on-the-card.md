## Capability statement
A trail card shows **real, sourced live conditions** — weather, streamflow, air, fire, permits — each stamped with its source, its age, and an honest confidence; and when a condition is unavailable it shows *legible silence*, never a blank or a false-clear. This is the vision's central payoff: the honesty primitives stop being decoration and start carrying real JIT-verified facts.

## Why now (the leverage)
The primary `/plan` surface currently returns cards with `lines: []` — trails with **zero sourced conditions**. Rules #1/#3 (source-or-silence + JIT overlays) are the product's whole differentiator and are presently **unexercised on the live surface**. Wiring conditions is the single biggest lever on the board (roadmap v10 dogfood).

## Current state — grounded in the code (READ THIS FIRST)
**The machinery is built end-to-end. The blocker is deployment config, not missing code.**

- **Backend path exists:** `verify()` (`orchestration/verifier.py`) → `summarize_fact()` (`orchestration/present.py`, already emits honest source-notes + origin ids + aggregator labels from the #54 CDP-01 wire) → `lines` built at `orchestration/engine.py:270` → serialized to `FeedLineResponse` at `api/app.py:141` → mapped to `conditionLines` in `frontend/src/data/http/httpPlanner.ts`.
- **Adapters emit origin fields already:** NWS `forecast_office`/`grid_x`/`grid_y` (`adapters/nws.py`), FIRMS `satellites[]` (`adapters/firms.py`), USGS `site_id` (`adapters/usgs_water.py`). NWS + USGS are **keyless**; AirNow/FIRMS/RIDB need keys.
- **The root cause of `lines: []`:** `orchestration/config.py:67` — `live_adapters` **defaults to `()`** ("Empty = no live probes"). Unless `ADVENTURE_LIVE_ADAPTERS` is set in the Render env, *no adapter runs*, so `verify()` returns `{}` → no lines. The deploy runbook already documents the env vars (`docs/runbooks/deploy-api-render.md:56-60`); they simply aren't set.
- **The one real code gap:** `frontend/src/screens/RecommendationCard.tsx:76` — `if (card.conditionLines.length === 0) return null`. Empty conditions render **nothing** (a blank thin card) instead of the honest silence CDP-02 requires.
- **Diagnostic already available:** `GET /health` returns `probes_available` (`api/app.py:208`) — the live deploy's enabled probes are directly observable.

## Architectural context
- **Builds on:** the LiveAdapter seam (Epic 013), the Verifier + `present.py` (#54), the honesty primitives (`Confidence`/`Signal`/`Staleness`, shipped), the secured/rate-limited `/plan` (#53), the deploy runbook (#40).
- **Enables:** the north-star card moment; the "surface corroboration" follow-on (corpus `corpus_confidence`); the eventual verdict layer (CDP-04) which reads these facts.
- **Does NOT include:** the go/marginal/no-go verdict reduction (CDP-04, later); readiness (Epic 007); auth/personal overlay (live conditions are **world data**, served on the anonymous path). This epic is world-conditions only.

## Stories (independently assignable lanes)

### S1 — Enable the keyless probes on the live deploy *(the unblock — ops lane, do first)*
**Given** the backend condition path is built but `live_adapters` is empty on Render,
**When** an operator sets the env and redeploys,
**Then** anonymous `/plan` at Shenandoah returns cards carrying real **weather (NWS)** and **streamflow (USGS)** lines.

- **AC-1.1** Set `ADVENTURE_LIVE_ADAPTERS=nws,usgs_water` and `NWS_USER_AGENT=<contact>` on Render per `docs/runbooks/deploy-api-render.md:56-60`; redeploy.
- **AC-1.2** `GET /health` `probes_available` lists `weather` and `water`.
- **AC-1.3** A real anonymous `POST /plan` at a Shenandoah origin returns ≥1 card whose `lines` includes a weather line and (where a gauge is near) a water line, each with `source` + a timestamp + a `confidence_level`.
- **AC-1.4** No secret is committed (Rule #10); `NWS_USER_AGENT` + any keys live only in Render config.

### S2 — Provision + enable the keyed sources *(ops lane, follows S1)*
**Given** AirNow/FIRMS/RIDB require API keys,
**When** keys are provisioned into Render config and added to `ADVENTURE_LIVE_ADAPTERS`,
**Then** air, fire, and permits conditions appear where available.

- **AC-2.1** Obtain + store `AIRNOW_API_KEY`, `FIRMS_MAP_KEY`, `RIDB_API_KEY` in Render (secrets only).
- **AC-2.2** Extend `ADVENTURE_LIVE_ADAPTERS` to include `airnow,firms,ridb`; `probes_available` reflects `air`/`fire`/`permits`.
- **AC-2.3** A missing key still self-drops that adapter cleanly (verify `from_config → None` path) — a partial key set never 500s; absent kinds are simply absent.

### S3 — Live-harden + regression-gate the adapters *(backend lane)*
**Given** adapters must never surface an unsourced or fabricated fact,
**When** each enabled adapter is exercised against the real API and against failure,
**Then** it returns a correct stamped `VerifiedFact` on success and `None` (source-or-silence) on any failure — provably, in CI.

- **AC-3.1** Live smoke test each enabled adapter at real Shenandoah coordinates; confirm correct `value`, `source`, `fetched_at`, and the origin fields (`site_id` / `forecast_office`+grid / `satellites`).
- **AC-3.2** Partial-failure honesty holds: NWS alerts sub-call failure → `active_alerts` omitted (not "no alerts"); USGS no-nearby-gauge → no water fact + the nearest-gauge-distance disclosure when present; any transport error → `None`, never a raised exception past the adapter.
- **AC-3.3** Recorded-cassette tests (record/replay of the real payloads) run in CI for every enabled adapter, so a schema/contract drift reds the build (ties Epic 009). Cassettes carry **no secrets**.
- **AC-3.4** Timeouts + the per-source TTL cache (`adapters/registry.py`) are confirmed active so a slow/999 source degrades-and-discloses rather than hanging the request.

### S4 — Honest condition rendering + the four silence states *(frontend lane — CDP-02)*
**Given** an honest app in a data-sparse spot must never read as broken or falsely clear,
**When** a card renders,
**Then** present conditions carry source + age + confidence, and *absent* conditions render a legible, distinct silence state.

- **AC-4.1** Each `conditionLine` renders its text with the **source**, a relative **timestamp**, and the confidence hedge via the existing `Confidence`/`Signal`/`Staleness` primitives (stated / hedged / flagged).
- **AC-4.2** Replace `RecommendationCard.tsx:76`'s `return null`: an empty/degraded conditions block renders one of **four visibly distinct states** (CDP-02) — **no-data** ("no source covers this here"), **checked-clear** ("checked, nothing to flag"), **not-fetched** ("tap to verify / fetching"), **stale-degraded** ("last known Nh ago — may have changed"). Same-looking gray for all four is a fail.
- **AC-4.3** A card with *some* kinds present and others absent shows both honestly (no implication that the present set is exhaustive).
- **AC-4.4** Wire contract unchanged where possible; if a new field is needed to distinguish silence states (e.g. checked-clear vs never-fetched), it is added to `FeedLineResponse`/`FeedCardResponse` with a frozen contract test (mirror `tests/test_maps_contract.py`).

### S5 — Guardrail interplay with live conditions *(backend lane — safety)*
**Given** conditions are not decoration — a real hazard must gate the trail,
**When** `evaluate_guardrails` sees a hazardous live fact,
**Then** the trail is set-aside with its **binding reason** surfaced, never silently dropped or shown as fine.

- **AC-5.1** A blocking live condition (e.g. active FIRMS fire nearby, an NWS hazard alert, or a flood-level streamflow if a threshold exists) sets the trail aside with the source-stamped reason.
- **AC-5.2** A set-aside trail is disclosed (ruled-out with its cause + source), consistent with source-or-silence — not removed with no trace.
- **AC-5.3** Confidence still never penalizes ranking (Rule #2): a hazard is a *safety* gate, not a taste demotion.

### S6 — Cost, caching & latency on the live fan-out *(backend/ops lane — R5 tie-in)*
**Given** each candidate fans out to up to 5 live sources,
**When** a real `/plan` runs against the live corpus,
**Then** cost + latency are measured, bounded, and the fan-out degrades gracefully.

- **AC-6.1** Instrument one real `/plan`: live-API call count, wall-clock per kind, and (with Anthropic in the path) tokens/$ per session — report the numbers (feeds R5 / open decision #5).
- **AC-6.2** Per-source TTLs are tuned to real volatility (weather hours, streamflow shorter, permits/day, per CDP-08) and confirmed to cut repeat calls within a feed.
- **AC-6.3** The `/plan` rate-limit (#53) is confirmed to cover the fan-out; a slow or rate-limited source discloses-and-degrades rather than failing the whole card.

## Sequencing & parallelism
- **S1 first** — it is the unblock and is tiny (env + redeploy); it turns `lines:[]` into real weather+water immediately and gives every other lane real data to test against.
- Then **S3 (harden)** + **S4 (frontend silence)** run **in parallel** — different files, no coupling beyond the (frozen) wire contract.
- **S2 (keys)** lands whenever keys are provisioned (independent of S3/S4).
- **S5 (guardrails)** + **S6 (cost)** follow S1 (need real live data); S6 pairs naturally with the standalone R5 cost spike.
- **Explicitly out / sequenced after:** surfacing corpus `corpus_confidence` on the card (#54's dead state) is a *follow-on* — it wants live facts to sit beside it, so do it after S4.

## Definition of Done
- [ ] On the live deploy, an **anonymous** `/plan` at Shenandoah returns cards with real weather + streamflow lines, each naming source + age + confidence.
- [ ] Absent conditions render one of the four legible silence states — never a blank card or a false-clear.
- [ ] A real hazardous condition sets a trail aside with its source-stamped reason.
- [ ] Every enabled adapter is regression-gated by a cassette test in CI (source-or-silence on failure proven).
- [ ] `/plan` live-fan-out cost + latency measured and within a stated budget; TTLs tuned; rate-limit confirmed.
- [ ] `make check` green; targeted review clean; no secrets in the repo.

## Risks / notes
- **NWS requires a real `User-Agent`** — `nws` silently returns nothing without `NWS_USER_AGENT`. S1 must set it.
- **Two-call latency (NWS `points`→`forecast`)** and per-candidate fan-out drive S6; the TTL cache is the lever.
- **AirNow is an aggregator** — `present.py` already labels it "single aggregated source" (CDP-01 spike); do not imply independent corroboration for air.
- **Anonymous path**: conditions are world data and must render for `viewer_id=anonymous` (no auth dependency) — verify the anonymous path runs `verify()` unchanged.
- **Contract discipline**: any wire change for the silence states gets a frozen contract test (mirror `tests/test_maps_contract.py`) so the frontend/backend lanes can't drift.
